# Tambo360 – Backend (Fork de desarrollo)

Este repositorio es un fork del backend desarrollado durante el programa de desarrollo del proyecto **Tambo360**, una plataforma SaaS orientada a la gestión de producción láctea.

⚠️ Este fork se utiliza únicamente con fines de portafolio y referencia técnica. El repositorio original pertenece al equipo del proyecto.

---

## Mi participación

Trabajé como **Backend Developer** en el desarrollo del backend principal.

Principales responsabilidades:

- Diseño de la **estructura base del backend**
- Desarrollo de **APIs REST con Node.js, Express y TypeScript**
- Modelado de base de datos con **PostgreSQL y Prisma**
- Configuración y despliegue del backend en **Render**
- Deploy de base de datos en **Neon**
- Implementación de un **servicio independiente de envío de emails** desplegado en Vercel para resolver limitaciones del hosting backend
- Soporte técnico al equipo backend en debugging y resolución de problemas
